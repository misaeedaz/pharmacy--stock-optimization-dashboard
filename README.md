# Pharmacy Inventory Dashboard

Power BI dashboard designed to improve visibility into pharmacy inventory movement, stock risks, and inventory utilization.

---

# Project Overview

This project demonstrates how operational inventory data can be analyzed to support pharmacy inventory management decisions inside healthcare organizations.

The dashboard focuses on identifying:
- Overstock situations
- Low stock risks
- Expiry risks
- Inventory value concentration
- Slow-moving inventory

---

# Dashboard Features

- Stock status classification
- Days-to-sell estimation
- Overstock detection
- Low stock alerts
- Expiry monitoring
- Fast-moving vs slow-moving item analysis

---

# Business Problem

Healthcare pharmacies often face operational issues such as:
- Excess inventory
- Frozen capital
- Medication shortages
- Expired products
- Unbalanced purchasing decisions

This dashboard helps improve operational visibility using existing inventory data.

---

# Operational Value

The dashboard can support:
- Better purchasing prioritization
- Inventory optimization
- Reduction of unnecessary stock accumulation
- Improved medication availability
- Faster inventory monitoring

---

# Tools Used

- Power BI
- Power Query
- DAX

---

# Data Used

The dataset used in this project is a sample/demo dataset created for educational and portfolio purposes.

No real patient or hospital-sensitive data is included.



---

# Key Questions Answered

- Which products are overstocked?
- Which items risk stock shortages?
- Which items move slowly?
- How much inventory value is tied up in slow-moving products?
- Which products require purchasing attention?
